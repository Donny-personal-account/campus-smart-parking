# 智慧校园停车

这是一个面向中南林业科技大学校园场景的微信小程序，主要解决“哪里能停车、还有多少空位、怎么走过去”这几个问题。用户可以直接查看停车场和车位状态，登录后还能使用路线导航和个人资料功能。

## 主要功能

- 查看校内停车场、总车位、空余车位和占用情况
- 按位置推荐附近停车场，并在地图中查看停车点
- 搜索目的地、规划路线并显示距离与预计用时
- 微信一键登录，支持游客浏览
- 查看和修改个人资料
- 位置授权提示与隐私说明

## 本地运行

1. 安装微信开发者工具并克隆本仓库。
2. 在开发者工具中选择“导入项目”，项目目录选择仓库根目录。
3. 复制 `config.example.js` 为 `config.js`，填写 CloudBase 环境 ID、后端地址和腾讯地图密钥。`config.js` 已加入 `.gitignore`，不要提交到仓库。
4. 将 `project.config.json` 中的 `touristappid` 替换为自己的小程序 AppID。
5. 开通微信云开发，在云开发控制台创建所需数据库集合，并上传 `cloudfunctions` 目录下的云函数。含依赖的云函数需要在上传时安装依赖。
6. 为 `getNavigation` 云函数配置 `BAIDU_MAP_AK` 环境变量；为 `apiProxy` 配置 `BACKEND_HOST` 和 `BACKEND_PORT` 环境变量。
7. 在地图服务平台限制密钥的使用范围，并分别完成开发者工具预览和真机测试。

项目启动后会从后端接口读取停车场与用户数据。当前仓库包含小程序端和云函数代码，不包含业务后端；如果后端服务不可用，登录、车位状态和资料更新等功能将无法正常工作。

## 主要技术

- 微信小程序原生框架（WXML、WXSS、JavaScript）
- 微信云开发与 `wx-server-sdk`
- 腾讯地图 WebService
- 百度地图路线规划

## 开发说明

- 停车场相关页面会申请定位权限，用于附近停车场推荐和路线导航。
- 后端请求统一通过 `utils/request.js` 和 `cloudfunctions/apiProxy` 处理。
- 修改云环境、地图密钥或服务地址后，请同时进行开发者工具预览和真机测试。定位、授权和地图跳转在模拟器中的表现可能与真机不同。
